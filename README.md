# WebDevLab03

CS 1301 Web Development Lab 03 - Card Game Analysis with Deck of Cards API and AI

## Features

This Streamlit application uses the Deck of Cards API (https://deckofcardsapi.com/) to:
- Shuffle and create new decks of cards
- Draw cards from decks
- Visualize card distributions with interactive charts
- Analyze card statistics

## Phase 1: Deck of Cards API Integration
- Phase 1a: Shuffle and create decks
- Phase 1b: Draw cards from decks
- Phase 2: Data analysis and visualization of card distributions
